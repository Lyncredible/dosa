# 25 · MS-DOS 6.22 built-in command parity

Use the Microsoft MS-DOS 6.22 User’s Guide and the Microsoft Help command reference as the compatibility baseline. Track commands implemented by COMMAND.COM separately from the utilities and drivers shipped on its disks. [Microsoft MS-DOS 6.22 User’s Guide](https://www.bitsavers.org/pdf/microsoft/msdos_6.22/DOS_6.22_Users_Manual_1994.pdf) [MS-DOS 6.22 Help command reference](https://dos-help.soulsphere.org/help.hlp/index.html)

| Area | Current behavior and remaining work |
| --- | --- |
| Directory listings | `DIR` supports `/W`, `/B`, `/L`, `/S`, `/P` pagination, filename patterns, and `/O` ordering by name, extension, date, size, or directory group. `DIRCMD` presets paths and switches, and `/-switch` overrides a preset. `/A` filters DOS attributes. Default listings hide hidden and system entries, and read-only mounts report file write protection. FAT flags, hidden ISO entries, and host permissions feed DOS and shell searches. Host mounts use UTC modification times. FAT, ZIP, and ISO images use recorded modification dates. `DIR` reports volume information, file counts, total bytes, and free space. DOS function 36h reads the same allocation data within its 16-bit limits. `/C`, `/CH`, and `/O:C` are accepted on ordinary DOS mounts, where entries tie on compression. DriveSpace and DoubleSpace volume support remains open. [DIR reference](https://dos-help.soulsphere.org/help.hlp/Dir.html) |
| Files and directories | `CD`/`CHDIR`, `TYPE`, `MD`/`MKDIR`, and `RD`/`RMDIR` work. Directory mutations use writable mounts and preserve the current directory and non-empty directories. `REN`/`RENAME` supports wildcard names within one directory. `DEL`/`ERASE` handles DOS filename patterns, `/P` per-file confirmation, and a confirmation before deleting all files in a directory. `COPY` handles mounted files, filename patterns, concatenation, overwrite prompts, `COPYCMD`, and `/A`, `/B`, and `/V`. Single-file copies preserve the DOS-visible modification time. Concatenated copies use the DOS session clock. `COPY` accepts `NUL` as empty input or a discard destination. `COPY CON` reads console text through Ctrl+Z and Enter or sends file data to the screen. Other device copying remains open. [RENAME reference](https://dos-help.soulsphere.org/help.hlp/rename.html) [DEL reference](https://dos-help.soulsphere.org/help.hlp/Del.html) [COPY reference](https://www.infania.net/misc/dos622help/copy.html) |
| Environment and prompt | `SET` lists, sets, and removes DOS variables. Batch files expand those variables, and launched programs inherit them through the PSP environment segment. `PATH` controls executable and batch search. `PROMPT` and `SET PROMPT` customize the prompt with the documented DOS substitutions. `$E` emits an escape byte. Opt-in ANSI text output supports cursor positioning, screen and line clearing, text colors and attributes, and line wrapping. Cursor reports, video mode changes, and keyboard reassignment remain open. [Microsoft ANSI.SYS reference](https://github.com/microsoft/MS-DOS/blob/main/v2.0/bin/ANSI.DOC) [SET reference](https://dos-help.soulsphere.org/help.hlp/SET.html) [PATH reference](https://dos-help.soulsphere.org/help.hlp/PATH.html) [PROMPT reference](https://dos-help.soulsphere.org/help.hlp/PROMPT.html) |
| Batch control | `CALL`, `ECHO`, `GOTO`, and `REM` work. `IF` tests error levels, string equality, and file existence with optional `NOT`. `SHIFT` advances numbered parameters, including arguments beyond `%9`. `PAUSE` waits for a key and supports Ctrl+C confirmation. `FOR` runs a command over literals and filename patterns at the prompt and in batches. Add the remaining batch interactions. See [task 17](17-batch-files.md). [IF reference](https://dos-help.soulsphere.org/help.hlp/IF.html) [SHIFT reference](https://dos-help.soulsphere.org/help.hlp/SHIFT.html) [PAUSE reference](https://dos-help.soulsphere.org/help.hlp/PAUSE.html) [FOR reference](https://dos-help.soulsphere.org/help.hlp/For.html) |
| System and session | `CLS`, `EXIT`, and drive changes work. `VOL` shows FAT labels and serial numbers and ISO labels. `DATE` and `TIME` share the adjustable DOS session clock with guest services and prompt substitutions. Guest file creation, truncation, and writes use the adjusted DOS clock for the modification time. `VER` reports the same DOS version as the guest version services. `VERIFY` shares its setting with DOS functions 2Eh and 54h and enables read-back for guest writes and `COPY`. `BREAK` shares the extended Ctrl+C checking setting with DOS function 33h. DOS checks cooked console calls and extends checks to filesystem calls with `BREAK ON`. Guest INT 23h handlers can resume an interrupted service with IRET. `CHCP` switches the built-in DOS console between OEM 437 and 850. DOS function 66h shares the setting. Text rendering, BIOS graphics text, keyboard input, clipboard text, and OEM batch text use these pages. `LH`/`LOADHIGH` loads fitting COM and MZ programs in upper-memory region 1 on the 286 and 386. It honors a minimum region size and `/S` for that region and falls back to conventional memory on the 8086 or when the image does not fit. Command arguments, PATH lookup, and redirection use the usual launch path. Linking region 1 for allocations by a conventionally loaded program, additional code pages, NLS files, guest keyboard layouts, and `CTTY` remain open. [LOADHIGH reference](https://www.infania.net/misc/dos622help/loadhigh.html) Track any dependencies on emulated devices, code pages, and memory managers. [DATE reference](https://www.infania.net/misc/dos622help/date.html) [TIME reference](https://www.infania.net/misc/dos622help/time.html) [BREAK reference](https://www.infania.net/misc/dos622help/break.html) [CHCP reference](https://www.infania.net/misc/dos622help/chcp.html) [VERIFY reference](https://www.infania.net/misc/dos622help/verify.html) |
| Command I/O | Guest programs can open `CON` and `NUL` with handle services. `NUL` discards writes and returns EOF. `CON` shares the keyboard and display with the standard handles. DOS functions 45h and 46h duplicate open handles with shared file positions and let guest handle-based reads and writes use redirected standard handles. Legacy DOS character and string output, including input echo, uses the current standard output handle. Fast console output through INT 29h still addresses the display. Legacy DOS character input, status checks, and buffered line input use the current standard input handle. Redirected EOF completes an empty or partial line. The shell uses `<`, `>`, and `>>` for builtins and DOS programs at the prompt, on individual batch lines, and across complete batches. Nested commands inherit stream positions unless they redirect a stream. Redirection accepts files, `CON`, and `NUL`. Pipes run successive commands against private buffered streams. They support multiple stages, filters, nested batches, and local redirection. Add the remaining DOS character devices. [MS-DOS redirection reference](https://msarchive.pcjs.org/mspl13/msdos/encyclopedia/section2/) [DOS device reference](https://msarchive.pcjs.org/mspl13/msdos/encyclopedia/section2/) |

Dosa documents `MOUNT` for files, directories, ZIPs, and disk images. `HELP MOUNT` lists the shell options. The legacy `IMGMOUNT` invocation still opens ISO images, and startup flags are documented in the README and command-line help.

Exercise the shell prompt, startup command, and batch paths with generated fixtures. Validate behavior on read-only and writable mounts before marking a command complete.
