# 25 · MS-DOS 6.22 built-in command parity

Use the Microsoft MS-DOS 6.22 User’s Guide and the Microsoft Help command reference as the compatibility baseline. Track commands implemented by COMMAND.COM separately from the utilities and drivers shipped on its disks. [Microsoft MS-DOS 6.22 User’s Guide](https://www.bitsavers.org/pdf/microsoft/msdos_6.22/DOS_6.22_Users_Manual_1994.pdf) [MS-DOS 6.22 Help command reference](https://dos-help.soulsphere.org/help.hlp/index.html)

| Area | Current behavior and remaining work |
| --- | --- |
| Directory listings | `DIR /W`, `/B`, `/L`, `/?`, and filename patterns work. Default listings show names and sizes. Add pagination, recursion, ordering, attributes, volume and space summaries, timestamps, and the `DIRCMD` environment. [DIR reference](https://dos-help.soulsphere.org/help.hlp/Dir.html) |
| Files and directories | `CD`/`CHDIR`, `TYPE`, `MD`/`MKDIR`, and `RD`/`RMDIR` work. Directory mutations use writable mounts and preserve the current directory and non-empty directories. `REN`/`RENAME` supports wildcard names within one directory. Add `COPY` and `DEL`/`ERASE` with wildcard and prompt behavior. [RENAME reference](https://dos-help.soulsphere.org/help.hlp/rename.html) |
| Environment and prompt | `SET` lists, sets, and removes DOS variables. Batch files expand those variables, and launched programs inherit them through the PSP environment segment. `PATH` controls executable and batch search. `PROMPT` and `SET PROMPT` customize the prompt with the documented DOS substitutions. `$E` emits an escape byte. ANSI interpretation remains open. [SET reference](https://dos-help.soulsphere.org/help.hlp/SET.html) [PATH reference](https://dos-help.soulsphere.org/help.hlp/PATH.html) [PROMPT reference](https://dos-help.soulsphere.org/help.hlp/PROMPT.html) |
| Batch control | `CALL`, `ECHO`, `GOTO`, and `REM` work. `IF` tests error levels, string equality, and file existence with optional `NOT`. `SHIFT` advances numbered parameters, including arguments beyond `%9`. `PAUSE` waits for a key and supports Ctrl+C confirmation. `FOR` runs a command over literals and filename patterns at the prompt and in batches. Add the remaining batch interactions. See [task 17](17-batch-files.md). [IF reference](https://dos-help.soulsphere.org/help.hlp/IF.html) [SHIFT reference](https://dos-help.soulsphere.org/help.hlp/SHIFT.html) [PAUSE reference](https://dos-help.soulsphere.org/help.hlp/PAUSE.html) [FOR reference](https://dos-help.soulsphere.org/help.hlp/For.html) |
| System and session | `CLS`, `EXIT`, and drive changes work. Add `BREAK`, `CHCP`, `CTTY`, `DATE`, `LH`/`LOADHIGH`, `TIME`, `VER`, `VERIFY`, and `VOL`. Track any dependencies on emulated devices, code pages, and memory managers. |
| Command I/O | Implement and verify DOS pipes, input/output redirection, and device names with commands and batch files. |

Dosa documents `MOUNT` for files, directories, ZIPs, and disk images. `HELP MOUNT` lists the shell options. The legacy `IMGMOUNT` invocation still opens ISO images, and startup flags are documented in the README and command-line help.

Exercise the shell prompt, startup command, and batch paths with generated fixtures. Validate behavior on read-only and writable mounts before marking a command complete.
