# 24 · Desktop controls and appearance

- **Reset guest.** Provide a menu action that stops a running or paused guest and batch, resets devices, and returns to the prompt with configured drives and settings.
- **Windows window frame.** Windowed Dosa uses a native menu bar below the title. The title shows CPU, speed, and drive. The app header provides menu access in fullscreen and on other platforms.
- **Menu shortcuts.** Windows handles the native menu's keyboard navigation. F10 opens the app-header menu from the prompt. Arrow keys and Enter navigate it.
- **Application icon.** The desktop uses an original terminal icon, and the Windows MSVC executable embeds 16, 24, 32, 48, 64, and 256 pixel variants.
