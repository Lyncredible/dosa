# 24 · Desktop controls and appearance

- **Reset guest.** Provide a menu action that stops a running or paused guest and batch, resets devices, and returns to the prompt with configured drives and settings.
- **Title-bar menu.** Replace the persistent row of category tabs with a single menu button in the title bar. Keep window controls, keyboard navigation, and scale-aware pointer hit testing. Verify fullscreen, resize, and native window drag on Windows.
- **Menu shortcuts.** Remove the displayed Alt-letter legend and stop intercepting those chords from DOS applications. Retain keyboard navigation inside the menu.
- **Application icon.** Draw an original icon and use it for the window and Windows executable. Verify the small title-bar size and Windows Explorer appearance.
