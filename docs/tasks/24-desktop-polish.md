# 24 · Desktop controls and appearance

- **Reset guest.** Provide a menu action that stops a running or paused guest and batch, resets devices, and returns to the prompt with configured drives and settings.
- **Windows title bar.** The current hamburger is in the app header. Move menu access into the Windows window frame, above the DOS render surface, with the appearance and interaction of a regular Windows menu. Show the current CPU and speed in the window frame without crowding the controls. Verify menu access, fullscreen, resize, and native window drag on Windows.
- **Menu shortcuts.** The Alt-letter legend and intercepts are removed. F10 opens the menu from the prompt, and arrow keys and Enter navigate it.
- **Application icon.** The desktop uses an original terminal icon, and the Windows MSVC executable embeds 16, 24, 32, 48, 64, and 256 pixel variants.
