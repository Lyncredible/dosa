# 24 · Desktop controls and appearance

- **Reset guest.** Provide a menu action that stops a running or paused guest and batch, resets devices, and returns to the prompt with configured drives and settings.
- **Windows window frame.** Windowed Dosa puts the emulator popup in the title bar. Click **Dosa ▾** or right-click the caption to open it. The caption shows CPU, speed, and drive alongside the Windows window controls.
- **Menu shortcuts.** F10 opens the emulator menu from the prompt. Arrow keys and Enter navigate it. The app header provides menu access in fullscreen and on other platforms.
- **Application icon.** The desktop uses an original terminal icon, and the Windows MSVC executable embeds 16, 24, 32, 48, 64, and 256 pixel variants.
